# Músicas dos cards de games

Adicione nesta pasta os arquivos de áudio licenciados com estes nomes:

- `get-low.mp3` — Need for Speed Underground 2
- `temos-a-forca.m4a` — Dragon Ball Z: Budokai Tenkaichi 3

O programa alterna reprodução e pausa ao clicar no card. Ao iniciar um jogo ou sair da seção Games, a música é interrompida.
